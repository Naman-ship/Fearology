# ☠️ Fearology

> **Enter the world of fear. Explore the unknown.**

Fearology is a horror-themed website dedicated to exploring the darker side of the world — from paranormal encounters and urban legends to creepy stories, mysterious places, horror movies, and unexplained phenomena.

## 🌑 About the Project

Fearology is a web-based horror exploration platform designed for horror enthusiasts. It brings together eerie stories, terrifying legends, paranormal mysteries, and creepy content in one immersive experience.

## ✨ Features

- 👻 **Urban Legends** — Explore terrifying legends from around the world.
- 🩸 **Creepypasta** — Read fictional horror stories and internet mysteries.
- 🕯️ **Paranormal** — Discover unexplained phenomena and supernatural encounters.
- 🏚️ **Haunted Places** — Explore stories surrounding mysterious and haunted locations.
- 🔪 **True Crime** — Explore crime-related mysteries and cases.
- 🎬 **Horror Movies** — Discover horror movies across different genres.
- 📖 **Submit Your Story** — Share your own horror stories with Fearology.
- ℹ️ **About Us** — Learn more about the project and connect with us.


2. Open the project folder.

3. Open `index.html` in your browser or use Live Server in VS Code.
